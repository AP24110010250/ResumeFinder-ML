# ML-Based Resume Screening and Candidate Ranking System

A Python and Machine Learning recruitment assistance application built with Streamlit and Scikit-learn.

The system helps recruiters evaluate candidate resumes against job requirements using a single **Random Forest Classifier** trained on historical hiring data, coupled with transparent rule-based requirement checking.

---

## 1. Features
- **Job Requirements Configuration:** Recruiter form with dropdown categories (`Job Role`, `Job Type`, `Education Level`) aligned directly with the training dataset.
- **Digital PDF Resume Extraction:** Multi-file digital PDF extraction powered by PyMuPDF (`fitz`) with automatic detection of unreadable/scanned PDFs.
- **NLP Text Preprocessing & Skill Extraction:** Robust boundary-checked skill extraction supporting all 60 dataset skills and canonical industry synonyms.
- **Single Random Forest Model:** Trained on `Rupa_dataset.csv` using stratified 70% Train / 15% Validation / 15% Test splitting with Scikit-learn's `ColumnTransformer` (SimpleImputer, OneHotEncoder, and TfidfVectorizer for skills).
- **Candidate Ranking:** Candidates are ranked strictly by descending predicted **Hire probability** generated by the Random Forest Classifier.
- **Transparent Rule-Based Checks:** Minimum experience, education level, and missing skills are checked separately and transparently (never falsely presented as features learned by the ML model).
- **Side-by-Side Candidate Comparison:** Compare 2 or 3 candidates across all attributes.
- **Manual Shortlisting & SQLite Database:** Modify candidate statuses (`Pending`, `Shortlisted`, `Not Shortlisted`) and persist records to SQLite.
- **Excel Export:** Download screened and ranked candidate tables in `.xlsx` format using OpenPyXL.
- **Analytics Dashboard:** Real-time Plotly charts showing ranking distributions and Random Forest feature importances.

## 3. Installation and Setup

### Step 1: Install Dependencies
Open PowerShell or Terminal and install the required packages:
```bash
pip install -r requirements.txt
```

### Step 2: Train the Random Forest Model
To train the model pipeline from the dataset:
```bash
cd ResumeScreeningSystem
python -m ml.train_model
```
*Note: The model is already trained and saved as `ml/model_pipeline.joblib`. You do not need to retrain it every time you launch the GUI.*

### Step 3: Run the Streamlit Application
Launch the web interface:
```bash
streamlit run app.py
```

### Step 4: Run Tests
Run the test suite to verify all modules:
```bash
python tests/test_parser.py
python tests/test_features.py
python tests/test_ranking.py
python tests/test_e2e.py
```

## 4. Machine Learning Implementation Details
- **Algorithm:** Single `RandomForestClassifier(n_estimators=100, max_depth=12, random_state=42, class_weight='balanced')`.
- **Target Variable:** `Final Decision` (`Hire` vs `Reject`).
- **Feature Pipeline:**
  - `Skills`: Cleaned and vectorized via `TfidfVectorizer(max_features=150)`.
  - Numerical features (`Experience (Years)`, `CGPA`, `Certifications Count`, `Project Count`, `Internship Experience`, `Years Since Graduation`): Imputed with `SimpleImputer(strategy='median')`.
  - Categorical features (`Education Level`, `Previous Job Title`, `Job Role`, `Job Type`): Imputed with `SimpleImputer(strategy='constant', fill_value='Missing')` followed by `OneHotEncoder(handle_unknown='ignore')`.
- **Dataset Partitioning:**
  - Total: 3,000 records
  - 70% Training: 2,100 records
  - 15% Validation: 450 records
  - 15% Testing: 450 records (Untouched test set accuracy: **72.89%**)
